# Security policy

## Supported code

Security fixes target the current `main` branch until versioned AnyList
releases begin. Older Scrob tags remain in the retained history and are not
maintained by the AnyList project.

## Reporting a vulnerability

Please use the repository's private security-advisory reporting flow rather
than opening a public issue. Include the affected route or integration, the
impact, reproduction steps, and any suggested mitigation. Do not include real
provider tokens, passwords, viewing history or other personal data.

If private reporting is unavailable, contact the repository owner through the
GitHub profile and request a private channel before sharing details.
