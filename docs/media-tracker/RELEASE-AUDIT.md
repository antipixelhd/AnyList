## Public repository audit (2026-09-20)

The standalone public repository is [antipixelhd/AnyList](https://github.com/antipixelhd/AnyList). A GitHub fork relationship is not required: GitHub documents duplicating an existing repository with its history, and GPLv3 permits distribution of modified source provided the license, source, notices and recipients' GPL rights are preserved. AnyList retains the complete Scrob commit history, `LICENSE.md`, a prominent README/About attribution, and `NOTICE.md`; protocol and migration identifiers remain unchanged where compatibility requires them.

The full Git object graph contains 604 commits. A content scan inspected 2,754 non-binary blobs up to 2 MB for private-key blocks and common GitHub, AWS, Google, Slack, Stripe and JWT credential forms. It found no private keys or provider-token formats. Four JWT-shaped values were the documented ARVIO public anonymous application key (role `anon`) across its current source/workflow copy and historical rotations; they are client identifiers intentionally distributed by the upstream integration, not account credentials. The historical path audit found only `.env.example`; runtime `.env*`, local login data, certificates, caches, logs, build output and dependency directories are ignored.

Canonical product documents and their reference/verification images now live under `docs/media-tracker` in this repository; the former external copy was moved, avoiding divergent planning sources. README links resolve inside the repository.

Automatic publication inherited from upstream is disabled. Docker and semantic-release workflows require manual dispatch, publish only to `ghcr.io/${{ github.repository }}`, and no longer target the upstream Scrob registries or Docker Hub. Pushes and pull requests run read-only backend/frontend CI, which can also be dispatched manually. The authenticated GitHub identity is `antipixelhd`; the first public push set `main` to audited commit `b5c40ad` without publishing a release or container.

The first public CI runs found missing backend test prerequisites: the SQLite test driver and a migrated disposable PostgreSQL schema. The driver is now locked in the development dependency group and CI installs it. A subsequent run on `08af76d` passed the frontend job and backend installation but still failed backend tests against an empty schema. The workflow now initializes that dedicated test database with Alembic before discovery. [CI on `169ab46`](https://github.com/antipixelhd/AnyList/actions/runs/35518952525) passed backend and frontend; final-head CI remains a release gate.

The [Public-ready core milestone](https://github.com/antipixelhd/AnyList/milestone/1) tracks CI, isolated deployment, device verification and owner acceptance. Current documentation no longer prints the test host address or neighboring-service inventory. Those details had been present in earlier published commits; a normal follow-up commit cannot remove historical copies. No credentials were found in the publication audit, but operational endpoints should not be treated as secrets or security boundaries.
